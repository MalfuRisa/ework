# EWork v1.0.0

EWork 支持从虹桥读取团队导航，打开或刷新页面时加载当前生效的分组和卡片。维护人员在虹桥发布导航变更，无需重新构建 EWork。

- 收藏和常用网址按当前导航清单显示，已下架的条目会隐藏。
- 部分分组读取失败时，页面会显示对应分组的提示。
- 容器部署支持通过运行时配置切换虹桥实例和团队环境。

## 部署

`frontend.zip` 和 `frontend.tar.gz` 包含同一份生产构建。选择任意一个解压到 Web 服务器的站点目录，确保站点能访问 `index.html` 和同目录下的 `config.js`。

团队虹桥模式下，在 `config.js` 中将 `window.ESHOP_CONFIG` 的 `dataMode` 设为 `remote`、`configType` 设为 `rainbow-bridge`、`environment` 设为团队的虹桥环境 key。将 `baseUrl` 设为 `/rainbow-bridge`，并在 Web 服务器上把该路径代理到团队虹桥实例。容器部署可参照仓库中的 `DOCKER.md`。

可以用 `sha256sum -c SHA256SUMS.txt` 校验同时下载的两个压缩包和 `RELEASE_NOTES.md`。
